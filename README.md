# IMDb Movie Review Sentiment Analysis

## 📌 Project Overview

This project performs **sentiment classification on IMDb movie reviews** using Natural Language Processing (NLP) and Machine Learning.

The goal is to classify movie reviews into two categories:

* **Positive**
* **Negative**

The project follows an end-to-end NLP workflow:

**Text Preprocessing → TF-IDF Feature Extraction → Logistic Regression → Prediction → Model Evaluation → Important Words Analysis**

---

## 📊 Dataset

**Dataset:** IMDb Dataset of 50K Movie Reviews

The dataset contains approximately **50,000 movie reviews** with two columns:

| Column      | Description                    |
| ----------- | ------------------------------ |
| `review`    | Movie review text              |
| `sentiment` | Positive or Negative sentiment |

Dataset source: Kaggle — IMDb Dataset of 50K Movie Reviews

---

## 🎯 Objective

The main objectives of this project are to:

1. Clean and preprocess movie review text.
2. Convert text into numerical features using **TF-IDF**.
3. Train a **Logistic Regression** classification model.
4. Predict whether a review is positive or negative.
5. Evaluate the model using:

   * Accuracy
   * F1-score
   * Classification Report
   * Confusion Matrix
6. Identify the **top 10 words associated with positive sentiment** and the **top 10 words associated with negative sentiment**.

## 🧹 Text Preprocessing

The review text is cleaned before building the machine learning model.

The following preprocessing steps are performed:

### 1. Lowercase Conversion

All text is converted to lowercase.

```text
"This Movie Was Great"
```

becomes:

```text
"this movie was great"
```

### 2. HTML Removal

IMDb reviews can contain HTML tags such as:

```text
<br />
```

These tags are removed from the review.

### 3. Punctuation Removal

Punctuation marks are removed from the text.

### 4. Number Removal

Numeric values are removed.

### 5. Tokenization

The review is separated into individual words.

### 6. Stopword Removal

Common English stopwords are removed using NLTK.

### 7. Lemmatization

Words are converted to their base form where applicable.

---

## 🔢 Feature Extraction — TF-IDF

After preprocessing, the text cannot be directly given to a machine learning model.

Therefore, **TF-IDF (Term Frequency-Inverse Document Frequency)** is used to convert the reviews into numerical features.

The vectorizer uses:

```python
TfidfVectorizer(
    max_features=50000,
    ngram_range=(1, 2),
    min_df=2,
    max_df=0.95
)
```

The model uses:

* **Unigrams** — individual words
* **Bigrams** — two-word combinations

For example:

```text
"excellent movie"
```

can produce features such as:

```text
excellent
movie
excellent movie
```

## 🤖 Machine Learning Model

### Logistic Regression

Logistic Regression is used as the text classification model.

The model learns patterns from the TF-IDF features and predicts:

```text
0 → Negative
1 → Positive
```

The dataset is divided into:

```text
80% → Training Data
20% → Testing Data
```

A fixed `random_state=42` is used to make the train/test split reproducible.

---

## 📈 Model Evaluation

The model is evaluated using:

### Accuracy

Accuracy measures the percentage of correctly classified reviews.

```text
Accuracy = Correct Predictions / Total Predictions
```

### F1-Score

F1-score combines precision and recall and is useful for evaluating classification performance.

The notebook also generates:

* Classification Report
* Confusion Matrix

### Results

Run the notebook to generate the actual results.

```text

```

The exact values may vary depending on preprocessing, duplicate handling, and the dataset file used.

## 🔍 Top 10 Important Words

Because Logistic Regression provides a coefficient for each TF-IDF feature, the coefficients can be examined to understand which words are strongly associated with each sentiment.

### Positive Sentiment

The 10 features with the largest positive coefficients are extracted as the most important positive features.

### Negative Sentiment

The 10 features with the most negative coefficients are extracted as the most important negative features.

The notebook displays these words along with their Logistic Regression coefficients.

Example format:

```text

--------------------------------

wonderful       ...

...
```

```text
Top 10 Negative Words

--------------------------------

...
```

The actual words and coefficient values should be taken from the notebook output.

## ⚠️ Important Note

The IMDb reviews are real-world text and may contain HTML tags, punctuation, spelling variations, and other noisy content.

Also, removing stopwords can sometimes remove words that are useful for sentiment, such as negation words. Therefore, preprocessing choices can affect model performance.

For this project, stopword removal and lemmatization are included to demonstrate the requested NLP preprocessing workflow.
